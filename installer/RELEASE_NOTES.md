## Что нового

- Отправка на телефон не падает, если в выбранной папке телефона есть закрытые подпапки (например, `Android/data` внутри `/sdcard`).
- Папку телефона можно ввести и по-виндовски: `sdcard\Music\` превращается в `/sdcard/Music`.
- Ошибки adb (нет adb, телефон не ответил) показываются понятным текстом, а не кодом.
- Все функции adb проверены из Windows-сборки Python: подключение по Wi-Fi, список устройств, сведения о телефоне, выбор и создание папок, сравнение и отправка файлов с кириллицей, пробелами и спецсимволами в именах.

## Windows 10/11 (64-bit)

**Установщик:** скачайте `SaltMusic-Setup-{version}.exe` и запустите. Права администратора не нужны. Установщик предложит поставить через winget то, чего нет на компьютере: FFmpeg, Deno, adb (отправка на телефон) и mpv (плеер). Для mpv Windows спросит права администратора.

Если какую-то программу поставить не удалось, установщик скажет об этом. Поставить её можно и потом:

```
winget install Gyan.FFmpeg DenoLand.Deno Google.PlatformTools shinchiro.mpv
```

Или укажите путь к ней в настройках Salt Music → «Прочее» → «Программы».

Windows может предупредить о неизвестном издателе: программа не подписана. Нажмите «Подробнее» → «Выполнить в любом случае».

## Linux

**Установщик:** скачайте `SaltMusic-Setup-{version}.run` и запустите двойным кликом или из терминала:

```
bash SaltMusic-Setup-{version}.run
```

Нужны Python 3.11+ и интернет: зависимости ставятся в отдельное окружение. Программа ставится в `~/.local/share/salt-music/app`, появляются ярлык в меню и команда `salt-music`. Права root не нужны. Системные программы мастер проверит сам и предложит поставить недостающие; вручную на Arch:

```
sudo pacman -S ffmpeg mpv deno android-tools zenity
```

Удаление: пункт меню «Uninstall Salt Music» или `bash SaltMusic-Setup-{version}.run --uninstall`. Без вопросов: `--unattended`.
